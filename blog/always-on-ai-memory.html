I Built an Always-On AI That Remembers Everything

Kat Laszlo · May 16, 2026

Most people's AI setup is a chat window. You open it, ask something, it forgets everything when you close the tab. Every session starts from zero.

Mine doesn't.

I have an AI assistant that knows my research, remembers our conversations, answers on WhatsApp and Slack when my laptop is closed, and costs $6/month in infrastructure. Here's the full setup.

The architecture

Four components, connected by git:

Your laptop — where the thinking happens. I use Claude Code for interactive work and Obsidian for the knowledge vault. Everything I write goes here first.

GitHub — the sync layer. My vault (262 pages of research, source summaries, concept pages, synthesis) lives in a repo. Every push makes it available to the rest of the system.

DigitalOcean droplet — a $6/month server running OpenClaw Gateway. It pulls from GitHub every 30 minutes, so it always has my latest research. It runs as a systemd service, so it restarts itself if anything crashes.

Channels — WhatsApp self-chat, Slack, and Discord. These connect to the droplet, not my laptop. They work when my laptop is closed, when I'm on a walk, when I'm in the shower and remember a question about a paper I read last week.

The data flows in one direction:

I push notes -> GitHub -> Droplet pulls -> OpenClaw has context -> It answers on WhatsApp/Slack

The knowledge vault

This is the part that actually matters. The infrastructure is plumbing. The vault is the brain.

The vault has a simple schema:

  • raw/ — immutable source documents. Transcripts, PDFs, research papers, screenshots. I never modify these.
  • wiki/ — structured synthesis. Source summaries, entity pages (people, companies), concept pages (ideas, frameworks), and synthesis pages that connect ideas across sources.
  • CLAUDE.md — the rules. How to read sources, how to write pages, how to cross-reference.

Every time I ingest a new source, the AI reads it, creates a structured summary, updates entity and concept pages, checks for contradictions with existing knowledge, and appends to the log. The vault compounds. After 30+ sessions, it contains connections I never would have made manually.

The key insight: the vault isn't a document store. It's a structured knowledge base with a schema, cross-references, and rules. When the AI reads it, it doesn't just search for keywords. It understands how ideas relate to each other because the structure encodes those relationships.

Model routing

Not every question needs the same model. A lookup doesn't need the same horsepower as designing a system architecture. OpenClaw routes by task type:

TaskModelWhy
Summarize, classify, extract, search, lookupHaiku 4.5Fast, cheap, no reasoning needed
Code, implement, debug, review, chat, replySonnet 4.6Balanced speed + quality
Analyze, design, architect, plan, strategyOpus 4.6Full reasoning capability
Default (unmatched)Sonnet 4.6Safe fallback

This means a quick "what did that paper say about X?" costs a fraction of a cent, while a "how should I architect this system?" gets the full model. I don't think about it. The routing handles it.

Scheduled jobs

The droplet runs cron jobs:

  • Daily threat intelligence scan (6am ET, weekdays) — reads instructions from a file, scans for relevant news, posts a digest to Slack. It checks previous reports for feedback and adapts.
  • Weekly intelligence summary (Monday 10am ET) — synthesizes the week's scans into a market opportunity report.
  • Daily monetization alerts (9am PT) — analyzes customer usage patterns, flags churn risks and expansion opportunities.

These run whether I'm awake or not. Monday morning, I open Slack and the week's intelligence is already there.

What this actually feels like

The best way I can describe it: I have a research partner who never sleeps, never forgets, and gets smarter every time I feed it something new.

Last week I was on a walk and remembered a question about how two different researchers define "agent experience." I texted it to myself on WhatsApp. By the time I got home, the answer was there — with citations to the specific pages in my vault where those definitions live.

That's the difference between "AI as a tool" and "AI as a system." The tool resets. The system compounds.

The cost

  • Infrastructure: $6/month (DigitalOcean droplet). GitHub, OpenClaw, and Obsidian are free.
  • API costs: This is the real bill. Opus calls for strategy work, Sonnet for day-to-day, Haiku for lookups. Model routing helps — a quick lookup costs a fraction of a cent, but a deep analysis session can run $5-10. I spend roughly what I'd spend on a couple SaaS subscriptions.
  • Time: One afternoon to set up. Weeks to build a vault worth having. But that's research I'd be doing anyway — the system just makes sure none of it gets lost.

How to build your own

  1. Start with the vault. Pick a topic you're actively researching. Create a CLAUDE.md with your schema. Ingest 5 sources. The structure matters more than the volume.
  2. Set up OpenClaw. Install it, connect your API keys, pair your channels. The OpenClaw docs walk through this.
  3. Get a droplet. Any $6 VPS works. Install OpenClaw, set up systemd, add a cron job to pull your vault repo.
  4. Configure model routing. Start with everything on Sonnet, then move lookups to Haiku and strategy to Opus as you learn which tasks need which model.

The whole thing is just git, a $6 server, and a markdown folder with rules. No vector databases, no embeddings pipeline, no Kubernetes. The simplicity is the point.
