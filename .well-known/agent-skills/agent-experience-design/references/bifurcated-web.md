# The Bifurcated Web

The web is splitting into two layers serving the same products through different interfaces.

## Two webs

**Visible web (humans)**: HTML/CSS/JS, brand storytelling, psychological pricing, SEO, conversion funnels, social proof.

**Invisible web (agents)**: llms.txt, AGENTS.md, structured metadata, machine-readable pricing, AVIO/GEO, MCP servers, compliance data.

## Brand-to-bot framework (Brent Turner, NEXT Conference Dec 2025)

Three interaction dimensions replacing B2B/B2C:
1. **Brand-to-bot**: brands must win over personal agents (price, values, trust signals, capability metadata)
2. **Bot-to-brand**: agents initiate interactions autonomously (booking, purchasing, registering)
3. **Bot-to-bot**: brand systems and personal agents transact directly

## AVIO replacing SEO

AI Visibility Optimization. SEO = being found. AVIO = being chosen. Agents don't show 10 results. They evaluate and pick one.

| Dimension | SEO | AVIO |
|---|---|---|
| Discovery | Keyword matching, PageRank | llms.txt, AGENTS.md, MCP Server Cards |
| Content | HTML with meta tags | Clean markdown, structured data, API catalogs |
| Trust signals | Backlinks, domain authority | Capability metadata, compliance data, uptime SLAs |
| Conversion | Click-through rate | Agent task completion, programmatic signup success |
| Measurement | Rankings, organic traffic | Agent inclusion rate, recommendation frequency |

## The great decoupling (Andreas Cappell, Accenture Song)

"You're using ChatGPT all day but only having brand contacts a few times a week." Agents filter decisions before they reach humans.
