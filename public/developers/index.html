Developer Resources

Everything you need to integrate with this site programmatically. MCP server, Agent Skills, and machine-readable endpoints.

MCP Server

Query notebook content via Model Context Protocol. Three tools: search, list topics, get full skill content.

curl -X POST https://katrinalaszlo.com/api/mcp \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'

Add to your MCP client config:

{
  "katrinalaszlo-notebook": {
    "type": "url",
    "url": "https://katrinalaszlo.com/api/mcp"
  }
}

Agent Skills

Install all 5 skills (ai-foundations, knowledge-systems, ai-system-design, agent-tools, agent-experience-design):

npx skills add https://github.com/katrinalaszlo/personal-site

16 reference files covering model architecture, training loops, data pipelines, wiki vs vector, LLM memory, knowledge architecture, AI system design, agent teams, agent evaluation, OpenClaw, Hermes, AX framework, agent-readable sites, mutual legibility, bifurcated web, and agent self-serve.
