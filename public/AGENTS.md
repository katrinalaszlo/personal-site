# katrinalaszlo.com - Agent Instructions

## Project Overview

Personal site and MCP server for Katrina Laszlo. Provides agent-readable content about AI systems, agent experience design, and SaaS pricing strategy. Static HTML served via Next.js on Vercel with serverless API routes.

## Key Files

- `public/llms.txt` - LLM-optimized profile (compact)
- `public/llms-full.txt` - Extended profile with notebook index
- `public/agents.json` - Structured JSON: expertise, projects, contact
- `public/openapi.json` - OpenAPI spec for MCP endpoint
- `public/skill.md` - Agent capability declaration
- `pages/api/mcp.js` - MCP server (JSON-RPC: query_notebook, list_topics, get_skill)
- `middleware.js` - Content negotiation (Accept: text/markdown)

## Agent Endpoints

| Endpoint | Method | Description |
|----------|--------|-------------|
| `/api/mcp` | POST | MCP server (JSON-RPC 2.0) |
| `/api/mcp` | GET | SSE endpoint |
| `/?mode=agent` | GET | Structured JSON overview |
| `/llms.txt` | GET | Compact profile |
| `/llms-full.txt` | GET | Extended profile |
| `/agents.json` | GET | Machine-readable data |
| `/.well-known/agent-skills/index.json` | GET | 5 installable skills |
| `/.well-known/mcp/server-card.json` | GET | MCP discovery |

## Content Negotiation

Send `Accept: text/markdown` to `/` or `/blog/:slug` to receive markdown instead of HTML.

## MCP Tools

- `query_notebook(query, topic?)` - Search notebook content
- `list_topics()` - List available skills and topics
- `get_skill(skill_name, include_references?)` - Get full skill content

## Coding Conventions

- Static HTML in `public/`, no React components
- API routes use ESM exports in `pages/api/`
- Blog posts: markdown source in `public/blog/*.md`, HTML generated by `public/blog/build.js`
